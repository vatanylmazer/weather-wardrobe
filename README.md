🌤️ Weather Wardrobe

A modern, sleek web application built with HTML, CSS, and JavaScript that fetches real-time weather data and gives smart, humorous clothing recommendations based on the temperature and weather conditions.

🚀 Features
- Real-time weather fetching via OpenWeatherMap API.
- Dynamic clothing and outfit suggestions based on temperature brackets.
- Rain and precipitation alerts.
- Responsive, glassmorphism-styled UI design.

🛠️ Built With
- HTML5
- CSS3 (Flexbox, Glassmorphism effects)
- JavaScript (Async/Await, Fetch API)
- OpenWeatherMap API

⚙️ Setup & Run
1. Clone this repository to your local machine.
2. Get a free API key from [OpenWeatherMap](https://openweathermap.org/).
3. Replace `YOUR_OPENWEATHERMAP_API_KEY` in `app.js` with your actual API key.
4. Open `index.html` in your browser or run it via Live Server.
